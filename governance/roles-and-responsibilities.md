# Roles y Responsabilidades

Este documento define los roles y responsabilidades clave para la gobernanza del repositorio, asegurando claridad en permisos, procesos y responsabilidades para mantener la calidad y el orden en el desarrollo colaborativo.

## Roles principales

- **Owner**: Responsable final del repositorio, toma decisiones estratégicas y aprueba cambios mayores.
- **Maintainer**: Gestiona pull requests, mantiene la integración continua (CI) y supervisa la gobernanza diaria.
- **Consultor Senior**: Crea y valida módulos, asegura la calidad técnica y metodológica.
- **Consultor Jr.**: Redacta contenidos, realiza pruebas y contribuye con documentación.
- **Cliente / Sponsor**: Revisa entregables ejecutivos y valida resultados.

## Permisos y procesos

- Solo el Owner puede aprobar merges finales en ramas protegidas.
- Maintainers pueden revisar y aprobar pull requests, gestionar issues y mantener flujos de trabajo CI.
- Consultores pueden proponer cambios mediante pull requests, pero requieren revisión para aprobación.
- El Cliente / Sponsor tiene acceso de solo lectura para revisión y feedback.

## Gobernanza y seguimiento

- Se documentan métricas clave en `governance/KPIs.md`.
- Auditorías y checklist de calidad se encuentran en `governance/audit/audit-checklist.md`.
- Cambios en roles o procesos deben comunicarse y documentarse oportunamente.
